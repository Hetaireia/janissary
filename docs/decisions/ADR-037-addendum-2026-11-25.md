# ADR-037 addendum — 2026-11-25 — traversal baseline provenance

**Addendum to:** [ADR-037](./ADR-037-traversal-normalization-probe-convergence-oracle.md)
**Status:** Proposed, with ADR-037
**Mints:** corrections to ADR-037 G2, README.md, BENCHMARK.md

## Why this addendum exists

ADR-037 G2 gated on no true-positive regression against the 0.323 baseline (ADR-037:54). The 0.323 was carried from BENCHMARK.md Amendment 30 and from the README into the ADR without a run behind it. Scoring the committed run directly puts traversal recall at 44/133 = **0.331**, and the repeatability claim the figure rests on does not hold as written. Under the old G2, a regression from 44 to 43 true positives (0.331 to 0.323) passed silently.

The same run's overall DAST-applicable line is TP 1,022, FP 0, FN 134, P 1.000, R 0.884, F1 0.938, matching BENCHMARK.md:2276 and README:57. Reproduction command: `python benchmark/track_a/score_dast_aware.py 'benchmark/track_a/runs/20261118T113000Z-janissary-r1'`.

Amendment 29's baseline (`20261112T180530Z-janissary-r1`) measures traversal TP 10, FN 123, recall 0.075. The +34 delta is real and reproduces exactly per family (4/1/3/2 to 11/18/12/3), so the attribution at BENCHMARK.md:2300-2307 stands.

## Discrepancy 1 — 0.323 is one true positive low

44/133 = 0.3308, printed 0.331. 0.323 is 43/133 = 0.3233. No run in the tree yields 43 TP: the tree yields 42 (`093521Z`) and 44 (`113000Z`, `080501Z`). BENCHMARK.md:2321 writes both "0.323" and "(44/133 TP)", which do not agree with each other.

Corrected at ADR-037:6, :11, :54, :71; README:48, :55, :85, :214; BENCHMARK.md:2321.

## Discrepancy 2 — the committed run is not the commit the figures are attributed to

`20261118T113000Z`'s manifest records `harness_commit 8ecb302`, not `f964339`. `8ecb302` is runner-only — `benchmark/track_a/runner.py` plus `tests/unit/test_runner_rc_split.py`, "treat rc=2 on safe cases as expected abort" — so detection behaviour is unchanged and the figures stay valid. But README:48 and :55 read as though the artefacts belong to `f964339`. Both now name the split.

## Discrepancy 3 — the validation triple is not three usable runs

The three `f964339` runs are `20261118T065815Z`, `20261118T080501Z` and `20261118T093521Z`:

| run      | findings | classes         | DAST TP  | traversal TP | state                    |

| 065815Z  | 0        | none            | unscored | 0            | empty findings file      |

BENCHMARK.md:2339's "standard deviation across TP, FP, and FN is zero" holds for FP only. `093521Z` reproduces Amendment 29's totals (988 TP, 168 FN, 0.922, 0.855) with 42 traversal TPs and `pathtraver-01` at 16 rather than 18. Amendment 30's "all other categories identical TP/FN to Amendment 29" (:2307) does hold for `113000Z` against Amendment 29 — the supported-classes subset is 978 TP on both — and fails only against `093521Z`.

Recorded as a bracketed correction note as the file's last line, :2340; the amendment body is otherwise left as the history it is.

## Related correction — README Known limitations

README:214 said the remaining traversal false negatives are "structurally undetectable rather than unimplemented". ADR-037's P1 and P3 detect traversal from response shape without an existence signal, so the claim is true only of the file-existence oracle. Qualified to "undetectable by that oracle", with the shape-based oracles named.

## Related correction - harness example floor

`benchmark/track_a/runner_3run_aggregation.py:15` shows `--floor 0.323` and `tests/integration/test_harness_aggregation.py:87` passes the same value. `--floor` has no compiled default (:294), so the example is the only place the gate's intended value is recorded.

The gate is functional: a failed floor sets failed (:364) and the runner exits EXIT_GATE (:399). The comparison is a bare >= against a recall rounded to six decimals (:356, :361), so a literal 0.331 floor would fail the 44/133 = 0.330827 baseline run it is meant to lock.

Both occurrences are corrected to 0.3308: it passes at 44 TP and fails at 43 (0.323308), closing the one-true-positive hole G2 now gates on.

## Consequence for G2

G2 now gates on 44/133 with per-family floors and a full-corpus requirement, so a one-TP regression fails and a repeat set of one empty plus one truncated run cannot carry a pass on a single real measurement.

## Not established here

- Why `093521Z` sits 34 DAST-applicable TPs below `113000Z` while coinciding with Amendment 29's totals. Measured, not diagnosed.
