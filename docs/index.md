## Brand assets

The horizontal wordmark, the gold emblem, and the colour palette reference live in [branding/](branding/). Use SVG for everything. The full asset pack (banners, social previews, app icons) is maintained outside this repository; see [branding/README.md](branding/README.md) for the palette, typography, and usage rules.

## What is not here

This directory also holds internal records: amendments, phase plans, session handovers, workflow notes, and the detection backlog. Those are history and process, not user documentation, and are not linked from here. If you are looking for something in that category, browse the directory directly or ask the maintainer.
