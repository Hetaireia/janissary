## Environment gotchas

- git push can fail with empty output on transient network errors. Always
  print $pushOut.Length before treating empty as success. Retry succeeds.

- PowerShell here-strings (@' ... '@) preserve trailing newline before the
  closing delimiter. Regex anchors use \r?\n to tolerate this.

- git diff in Windows PowerShell renders unicode symbols (plus-minus,
  em-dash) as CP437 mojibake. Files on disk are correct UTF-8. Do not
  re-write based on diff output.
