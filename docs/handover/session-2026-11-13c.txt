3.1 Recorder module (Stage 1)

  src/janissary/harness/pathtraver.py provides PathtraverRecorder with
  structural signature (_structural_signature via fingerprint -> root_signature
  -> hamming is NOT what this is; the signature is SHA-256 of normalised body
  after UUID/hex/base64 masking and HTML tag stripping), evidence_hash (SHA-256
  of complete original body before truncation), and _derive_classification
  (six branches matching oracle silent branches in design §5 order:
  fires -> payload leak -> baseline poison -> signal fail -> signals agree ->
  unreconstructable).

  BODY_STORE_LIMIT = 4096 characters. Recorder failure isolation is nested:
  the try covers _build_record, json.dumps, and file write; the failure-log
  write has its own try that never raises; diagnostics counters
  records_attempted/records_written/failures_total are consistent for all paths.

3.2 Scanner integration (Stage 2)

  Scanner.__init__ gains record_case_dir: Path | None = None. When non-None,
  harness module is imported lazily and PathtraverRecorder is constructed with
  case_id=record_case_dir.name, raw_path=record_case_dir/"case_records_raw.jsonl",
  failure_path=record_case_dir/"recorder_failures.jsonl".

  Two methods added before scan():
    _maybe_record_observation - `with contextlib.suppress(Exception):` around
      recorder.record() with all eight kwargs. Silent failure from scan's
      perspective.
    _write_recording_status - writes recording_status.json with
      recording_enabled:true, recorder_constructed:true, records_attempted,
      records_written, failures_total, failure_log_written, scanner_version,
      completed_at (ISO 8601 UTC). Best-effort: try/except Exception pass.

  Call-site wrap: self._maybe_record_observation(...) inserted after
  oracle = check_pathtraver_oracle(...) and before for f in oracle:.
  Status write: self._write_recording_status() before final return summary.

3.3 CLI integration (Stage 3)

  --record-case-dir PATH flag on scan subparser. type=str, default=None,
  metavar="PATH", help text mentions M83, empty, writable, sanitized basename,
  pathtraver-only.

  _validate_record_case_dir validates: no ".." path segments (checked against
  Path.parts of the *supplied* path, not resolved), path exists, is a directory,
  is not a symlink itself, contains no prior recorder output files

  writable via exclusive open("x") probe (never overwrites user file; unlink

  In cmd_scan: validation runs after show_version check, before openapi/
  url/sessions branches. Returns 64 on failure. On success, converts
  args.record_case_dir to Path. _build_scanner forwards to Scanner.

6.4 The twelve operational traps

  Every command written this session, and every trap encountered, converged on
  these twelve. Carry them forward verbatim.

  1.  wsl bash -c variable interpolation. PowerShell expands $var before bash
      sees it. \" does not escape. Use 'single quotes' for literal strings,
      or avoid $ entirely.

  2.  [IO.File] resolves relative paths against CurrentDirectory, not
      PowerShell's Set-Location. Use (Resolve-Path $p).Path for every
      [IO.File] call.

  3.  PowerShell git commit fails against .githooks WSL venv path. No output,
      no commit. Use wsl bash -c with `source .../activate` before git.

  4.  Empty $edits = @( parse failure yields 0 items. Guard
      `if ($edits.Count -eq 0) { throw }` before the loop. A guard checking
      `$applied -ne $edits.Count` passes 0 -ne 0 silently.

  5.  git show | Out-File is not byte-transparent. Encoding checks against
      piped output are unreliable. Use [IO.File]::ReadAllBytes on the working
      tree plus git show --stat as the authoritative pair.

  6.  throw inside top-level if does not halt under $ErrorActionPreference =
      'Continue'. Always set $ErrorActionPreference = 'Stop' as first line
      of any script block. Verify-and-commit must be in the same script
      block, inside the success branch of the guard.

  7.  Anchor built from rendered paste instead of raw bytes. A terminal
      rendering may strip markdown backticks or normalise whitespace.
      Verify anchors against [IO.File]::ReadAllText content, not pasted
      output.

  8.  Verify and commit in separate paste lines. The commit will run against
      a state the verify did not check. Gate the commit on the verify in the
      same paste.

  9.  PS placeholder template `<message>` run verbatim. A commit template
      with angle-bracket placeholders must be filled in before execution.
      A literal `<message>` message lands in history.

  10. git show | Select-String with non-ASCII patterns fails silently. The
      Unicode pattern does not match after piping. Verify ASCII substrings,
      or use [IO.File]::ReadAllText on the working tree plus commit-stat
      line counts.

  11. Missing trailing newline on [IO.File]::WriteAllText -> ruff W292. Every
      here-string file write must be followed by
      [IO.File]::AppendAllText($p, [string][char]0x0A). Occurred three times
      this session: test_harness_pathtraver_signature.py (data-id),
      test_harness_runner.py (fail-closed test), test_harness_e2e.py.

  12. PowerShell escape character is BACKTICK, not backslash. Inside a
      PowerShell double-quoted string, "\\n" writes literal backslash+n.
      Control characters use backtick-n (newline), backtick-r (carriage
      return), backtick-t (tab), backtick-doublequote (literal quote). For
      characters whose escape sequence is not obvious, prefer
      [string][char]0xNN (0x0A = LF, 0x2014 = em dash, 0x00A7 = section sign,
      0x60 = backtick). This is unambiguous at every layer.

  Subsidiary (three additional but less frequent):
  -  Multi-section `cmd1 && cmd2 && cmd3` in a single wsl bash -c chain can
     silent-return to prompt with no output. One substantive command per
     `wsl bash -c` invocation. The environment-activation prefix
     (`cd ... && source ... &&`) is safe because it contains no quoting.
  -  Heredoc through PowerShell -> bash truncates. Write heredoc content to
     a file with [IO.File]::WriteAllText, then `bash /path/file.sh`.
  -  Notepad paste strips markdown syntax (backticks, asterisks, pipes) when
     copying from a rendered view. Use Get-Clipboard -Raw or a direct
     [IO.File]::WriteAllText here-string for markdown files.
