§7 — Environment limitations (new this session)
Unchanged: pre-commit broken; PS7 no heredocs; code <newpath> opens
unsaved buffer; gh run view needs numeric ID; < reserved.

NEW: git commit -m $msg with heredoc $msg is fragile. Em dashes and
other non-ASCII in commit messages can break argument passing in
PS7. Use repeated -m "short" arguments, or write $msg to a file
outside the repo via [System.IO.Path]::GetTempFileName().

NEW: Set-Content does not halt sequence on failure inside & { }.
Even with $ErrorActionPreference='Stop', a throw must be followed by
a loud ">>> STOP" Write-Host line, and any subsequent paste must
re-verify preconditions (HEAD, staged, file content) before acting.

NEW: git status --porcelain gives M / ?? / D prefixes with no summary
- critical for diagnosing "why didn't git add work" without parsing
the full output.

NEW: $env:TEMP resolves to 8.3 short path that Remove-Item cannot
reach. Use [System.IO.Path]::GetTempFileName(), not $env:TEMP paths.

NEW: transient 0xc0000005 git crash in gh run view during CI poll
loop - cosmetic, next poll recovers. Do not treat as real failure.

§8 — Session lessons (prior all still apply; new this session)
1. Heredoc -m $msg is fragile; use multi -m args or a file outside
   the repo.
2. Em dash in commit subject can break argument passing on PS7.
3. Prefer full-file rewrites (Set-Content) over surgical edits when
   the file is under 100 lines. Faster, fewer anchors to break.
4. & { } wrapper is necessary but not sufficient: add explicit
   pre-flight checks at the START of every commit/push paste.
5. STOP markers must be loud (Write-Host -ForegroundColor Red with
   >>> tokens), not just a throw.
6. ResponseSnapshot fields: status, body, normalized, fingerprint,
   length, normalized_length, elapsed, content_type. No status_code.
7. BaselineArmingState fields: armed, reason, fingerprints (tuple of
   int), root_signature, sample_count, hamming_max.
8. fingerprint() returns StructuralFingerprint; the 64-bit value is
   .value. hamming() takes ints, not StructuralFingerprint objects.
9. ADR-006 D7 second clause confirmed at code time: armed=True +
   root_signature=None does NOT gate 1.3d. Test
   test_armed_with_root_signature_none_still_emits verifies.
10. The 0xc0000005 git crash in gh run view is transient.
11. When paste A must precede paste B, the last line of A on failure
    must say ">>> STOP. Do NOT run paste B. <<<" not just a throw.

oracle or production code.

   no_markup requires a marker and tiny_body requires ":" or "/" but
   priority is no_markup > known_file > tiny_body - so tiny_body
