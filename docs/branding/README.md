# JANISSARY Brand Asset Pack

Approved identity: Carbon Black + Aurum Gold + Platinum.  
Tagline: **SIGNAL OVER NOISE.**

## Contents
- `logos/` — horizontal, stacked and standalone vector logos, with PNG previews
- `icons/` — application icon, favicon SVG/PNG/ICO
- `banners/` — GitHub banner and social preview graphics
- `guidelines/BRAND-GUIDELINES.md` — palette, typography, usage and messaging rules

## Recommended use
Use SVG wherever possible for crisp scaling. Use the 1024px app icon for product packaging and the ICO/SVG favicon for web projects. GitHub banner and social preview dimensions are included in the filenames.

The emblem and wordmark are clean vector artwork. Font appearance can vary by environment; use Montserrat and Inter for closest matching.
