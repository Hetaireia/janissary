# Branding

Assets used by the project README and any future documentation site.

## What's here

| File | Purpose |
|---|---|
| `janissary-horizontal.svg` | Primary wordmark + emblem. Used in README hero. |
| `janissary-emblem-gold.svg` | Emblem alone. Use for favicons, avatars, tight spaces. |

## Usage rules

From the brand guidelines:

- Prefer `janissary-horizontal.svg` for README headers, documentation and web headers.
- Use the stacked variant for square or centered placements.
- Use the gold emblem for favicons, app launchers and avatars.
- Keep clear space around the mark at least the width of one emblem stroke.
- Never stretch, skew, rotate, outline, or recolour the mark outside the approved palette.

## Colour palette

| Name | HEX | Use |
|---|---|---|
| Aurum Gold | `#D4AF37` | Primary accent, emblem, key highlights |
| Carbon Black | `#0B0B0F` | Primary background |
| Steel Grey | `#4B5057` | Secondary surfaces and dividers |
| Platinum | `#EBEBEB` | Text, light mark, high-contrast details |

## Typography

- Display / wordmark: Montserrat SemiBold or Bold; restrained tracking.
- UI and body: Inter Regular / Medium.
- Code and technical data: JetBrains Mono.

The SVGs use widely supported font fallbacks. For exact brand typography, install the fonts above in the design or build environment.

## Where the full pack lives

The complete asset pack (banners, social previews, application icon, favicon ICO, colour palette PNG, brand guidelines markdown, additional logo variants) lives outside this repository, in `Documents/Janissary-Brand-Asset-Pack/` on the maintainer's machine. Only the two SVGs the README needs are tracked here, because:

- `.svg` files are small (under 2 KB each) and scale cleanly.
- Banner and social-preview PNGs are uploaded via the GitHub web UI (Settings —> Social preview), not committed to git.
- The favicon ICO is only relevant if a documentation site is built later.

If you are contributing and need a brand asset that is not in this folder, ask the maintainer.
