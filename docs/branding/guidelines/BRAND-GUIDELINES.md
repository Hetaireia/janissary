# JANISSARY — Brand Guidelines

**Tagline:** SIGNAL OVER NOISE.  
**Positioning:** Precision-led application security testing.  
**Personality:** Disciplined, intelligent, dependable, technically assured.

## Core identity
The angular J emblem is the primary recognition device. It should be used as a standalone mark at small sizes and paired with the JANISSARY wordmark for first-contact brand placements.

## Colour system
| Name | HEX | Use |
|---|---|---|
| Aurum Gold | `#D4AF37` | Primary accent, emblem, key highlights |
| Carbon Black | `#0B0B0F` | Primary background |
| Steel Grey | `#4B5057` | Secondary surfaces and dividers |
| Platinum | `#EBEBEB` | Text, light mark, high-contrast details |

Use gold deliberately. It is an identifying accent, not a fill for every interface element. Maintain strong contrast for all functional text.

## Typography
- **Display / wordmark:** Montserrat SemiBold or Bold; use restrained tracking.
- **UI and body:** Inter Regular / Medium.
- **Code and technical data:** JetBrains Mono.

The SVGs use widely supported font fallbacks. For exact brand typography, install the fonts above in the design or build environment.

## Logo usage
- Prefer `janissary-horizontal.svg` for README headers, documentation and web headers.
- Use `janissary-stacked.svg` for square or centered placements.
- Use `janissary-emblem-gold.svg` for favicons, app launchers and avatars.
- Use the platinum emblem on dark monochrome applications.
- Keep clear space around the mark at least the width of one emblem stroke.
- Never stretch, skew, rotate, outline, or recolour the mark outside the approved palette.
- Avoid placing gold marks on busy or low-contrast backgrounds.

## Digital assets
- GitHub repository banner: 2560 × 640 px.
- GitHub social preview: 1200 × 628 px.
- Application icon: 1024 × 1024 px.
- Favicon: SVG plus multi-size ICO.

## Voice and messaging
Use concise, evidence-led language. Emphasise precision, signal quality, actionable findings and engineering trust. Avoid exaggerated claims such as “unhackable” or “zero risk.”

**Brand line:** SIGNAL OVER NOISE.
